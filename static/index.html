完全访问的风险
  • Agent 可以修改工作区外的本机文件。
  • 命令直接在主机环境运行，不再受 bwrap 隔离。
  • 网络访问开启，数据可能被发送到外部服务。
  • 仅建议在可信项目和受控设备上临时使用。
仍然生效的硬保护
删除系统目录、磁盘格式化等灾难性命令仍会拒绝
写入 /etc、/boot、/dev 等系统保护目录仍会拒绝
每次工具调用仍写入审计记录
